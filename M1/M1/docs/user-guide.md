# User guide

## Athlete
- **My Profile** — register and maintain personal, sport and anthropometric details.
- **My Injury History** — record previous injuries and current medical conditions.
- **Upload Video** — submit a movement video link for staff review.
- **Analysis Results** — see biomechanics, movement quality and recommendations for your videos.
- **Analytics** — personal risk score, quality progression, symmetry and joint metrics.
- **Alerts** — notifications when an analysis flags elevated risk.

## Coach
- Athlete list and athlete registration.
- Analytics: squad risk distribution, movement-quality trends, athletes needing attention.
- Reports and report builder with PDF / Excel / CSV export.
- Alerts across the squad.

## Physiotherapist
- Injury management view of athletes with recorded injuries or medical conditions.
- Rehab-oriented analytics (caseload, risk bands, factor breakdown).
- Reports, report builder and alerts.

## Sports scientist
- Video analysis: run pose estimation on submitted videos and save the results.
- Biomechanical analytics and symmetry comparisons.
- Reports, report builder and alerts.

## Administrator
- User directory with assigned roles.
- Platform analytics: users by role, videos submitted, analyses run, alert volume.
- Full athlete list, reports, report builder and system settings.

## Generating a report
1. Open **Report Builder**.
2. Choose an athlete (or the full squad), a report type and an optional date range.
3. Select **Generate report**.
4. Export with **PDF**, **Excel** or **CSV**.
