# Milestone 2 — Video Analysis & Biomechanics

This milestone focuses on analyzing athlete movement videos using pose estimation and extracting biomechanical insights.

## Features

* Upload and process movement videos
* Pose estimation using MediaPipe (33 keypoints)
* Skeleton overlay generation on video
* Joint angle calculations (knee, hip, elbow)
* Trunk lean measurement
* Range of motion analysis
* Left/right symmetry evaluation (LSI)

## Outcome

* Processed video with pose overlay
* Extracted biomechanical metrics for further analysis

## Notes

* Works best with clear and properly aligned videos
* Camera angle can affect certain measurements (e.g., knee valgus)
