# API Documentation

## Auth
- `POST /api/auth/login`
- `POST /api/auth/register`

## Athletes
- `GET /api/athletes`
- `POST /api/athletes`
- `GET /api/athletes/{id}`

## Videos
- `POST /api/videos/upload`
- `GET /api/videos/{id}`

## Analysis
- `GET /api/analysis/{id}/results`
- `POST /api/analysis/{id}/predict`
