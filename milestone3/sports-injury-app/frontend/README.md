# Milestone 3 — Injury Risk Scoring

This milestone introduces an injury risk scoring system based on multiple athlete performance factors.

## Features

* Generates a risk score (0–100)
* Combines multiple data sources:

  * Biomechanical analysis
  * Movement asymmetry
  * Injury history
  * Training load (ACWR)
  * Fatigue trends

## Key Highlights

* Explainable scoring with factor-wise breakdown
* Handles missing data without assumptions
* Designed as a decision-support tool

## Outcome

* Clear injury risk score
* Insight into contributing risk factors

## Notes

* Not clinically validated
* Should be used for guidance, not diagnosis
