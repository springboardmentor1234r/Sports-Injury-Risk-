# Sports Injury Risk Detection Platform

A comprehensive platform leveraging computer vision and machine learning to analyze athlete movements and predict injury risks.

## Quick Start

1. Clone repository
2. Run `./setup.sh` (Linux/Mac) or `./setup.ps1` (Windows)
3. `docker-compose up -d`
4. Visit `http://localhost:3000`

See `docs/README.md` for complete documentation.
